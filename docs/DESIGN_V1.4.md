# v1.4 设计与开发文档 —— 批改闭环 · 快速选题 · 套路掌握地图

> 2026-07-08。基于 v1.3 的一次整体迭代规划,围绕用户点名的六项需求。
> 配套调研:探索代理已对全部 2400 行代码做过架构测绘,本文档结论以其报告为准。

## 0. 需求 → 方案总览

| 需求 | 现状 | v1.4 方案 |
|---|---|---|
| ① 方便快速选题 | 选题散在题库/刷题/打印三处,路径长 | 首页「⚡ 快速出题」面板:模型/难度/数量三步,一键**上屏刷题**或**组卷打印**;支持"薄弱优先"自动选 |

## 1. 调研结论(现状缺口)

- 打印中心组卷时每题已有**可复现 id**(题库 `b3_q87` 式 / 生成题 `g_<tag>_<level>_<seed>` 式),但 `selected` 是模块级临时 Map,切页即丢;卷面上只印「第 N 题」顺序号,**无任何稳定关联键** → 纸面批改对不上题。
- 判分现状:屏上刷题两种方式——生成题输入答案自动判分、无生成器题自评;题库纯自评。纸面没有任何回录通道。
- 同步合并规则(attempts 去重 / errorBook 新者胜 / mastery 重放)成熟,新数据只需并入同一框架。
- 顺手修的技术债:`BANK_LEVEL`/`BANKS` 常量在 bank.js 与 print.js 重复定义 → 抽到 data.js。

## 2. 核心新功能:卷子档案 + 批改中心

### 2.1 数据结构(store.js)

每个学生档案新增 `sheets` 数组(旧数据无此字段,访问时惰性补 `[]`,不升 state version):

```js
sheets: [{
  id: 's_<Date.now().toString(36)>',   // 全局唯一,同时是同步合并键
  code: '0708-K3Q',                    // 卷号:月日-3位大写码,印在卷面上,家长凭它找卷
  ts: 1720…,                           // 组卷时间
  title: '今日特训卷' | '自选 8 题' …, // 来源描述
  items: [{ num, qid, tag, level, variantOf }],  // 与卷面「第 N 题」一一对应
  grades: { "1": true, "2": false, … } | null,   // num → 对错;null = 未批改
  gradedAt: null | ts,
}]
```

- 只存 id 不存题面(与错题本同思路),题干靠 `QMAP.get(qid) || regenerate(qid)` 还原。
- 封顶保留最近 **60 张卷**,防 localStorage 膨胀。

### 2.2 落库时机与卷面标识

- 打印中心点 **🖨 打印** 时落库(生成预览不落库,避免垃圾卷),并弹提示「已存档为卷 0708-K3Q,批改时去批改中心录入」。
- `buildSheetsHTML` 卷头新增 `卷号:0708-K3Q`;答案页同印。题目仍用「第 N 题」,回录靠 app 内 num↔qid 映射,**不需要**在卷面印题目 id 或二维码。

### 2.3 批改中心 `#/grade`

- 入口:首页快速行动区 +「打印中心」顶部;顶栏错题本旁不加图标(保持顶栏克制),但**有未批改卷时首页显著提示**。
- 卷列表:未批改置顶(高亮),已批改显示得分;按时间倒序。
- 批改页:逐题一行 = 题号 + 题干前 40 字 + 两个大按钮 **✓ / ✗**(点击互斥切换,适合手机上快速点);顶部「全对 ✓」快捷键;底部实时统计「已批 x/y · 对 z」。
- **保存规则(关键)**:点「保存批改」后逐题写入:
  - 每道已标记的题 → `recordAttempt({qid, tag, correct, mode:'paper', level})`;
  - 错题:若已在错题本 → `addError` 重置回第 0 盒(等同屏上再错);否则新建入本;
  - 对题:若该题在错题本且未掌握 → `reviewResult(qid, true)` 正常升盒(纸卷复习与屏上复习同权);
  - 未标记的题不写任何记录,卷子记 `gradedAt`,**已保存的对错不可改**(防止重复计入 attempts),未标记的题可后续「补录」。
- 空卷/垃圾卷可删除(不影响已写入的 attempts)。

### 2.4 同步合并规则(sync.js mergeInto 扩展)

```
sheets:两侧按 id 并集去重;同 id 冲突时 gradedAt 新者胜
       (未批改 < 已批改;都已批改取 gradedAt 大者);
       合并后按 ts 排序,保留最近 60 张。
```

attempts 本身已按 (ts,qid) 去重,纸卷写入的 attempts 走既有通道,无需新规则。

## 3. 快速出题(首页面板)

三步交互,全程不离首页:

1. **选范围**:四大母套路 chip(点选=该套路全部模型)或单模型下拉;或点「🎯 薄弱优先」自动取 `weakestTags` 前 3;
2. **定量**:难度(⭐/⭐⭐/⭐⭐⭐/自适应)× 数量(4/6/8/10);
3. **去向**:「▶ 上屏刷题」→ 新增 drill `custom` 模式(接收预置题单,做完出成绩单,判分沿用现有两套逻辑);「🖨 组卷打印」→ 生成题目 `preselectForPrint` 后跳打印中心自动出预览。

实现:home.js 渲染面板;drill.js 增加 `setCustomPlaylist(items)` 模块接口 + `#/drill/custom` 路由分支(与 daily/review 同构)。

## 4. 套路掌握地图

**四级阶梯**(status.js 新增 `masteryLevel(tag)`,单一事实来源):

| 级 | 名 | 判定(基于 mastery[tag] + errorBook) |
|---|---|---|
| 0 | ⚪ 未学 | seen = 0 |
| 1 | 🌱 学习中 | seen < 10 或 正确率 < 70% |
| 2 | 💪 熟练 | seen ≥ 10 且 正确率 ≥ 70% |
| 3 | 🏆 精通 | seen ≥ 20 且 正确率 ≥ 85% 且 该模型无未掌握错题 |

- 模型卡:右上角显示阶梯徽标;卡内进度条颜色随级别。
- 母套路组头:聚合进度条(组内各模型级别均值 / 3)+「x/n 模型已熟练」。
- 「基础综合」不在四套路内,单独一行。

## 附:本次自主决策点(如与预期不符,提出即改)

1. **落库时机选「点打印时」**而非「生成预览时」——避免反复调预览产生垃圾卷。
2. **已保存的批改不可改、未批的可补录**——保护 attempts 不被重复计入;判错了个别题的代价(删卷重印)远小于数据被刷乱。
3. 卷面**不印题目 id/二维码**,只印卷号——家长凭卷号进 app 找到卷,题号自然对齐,卷面保持干净。
4. 掌握四级阈值(10/70%、20/85%)是**起始值**,写成 status.js 顶部常量,便于按孩子实际情况调。
