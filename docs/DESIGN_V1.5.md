# v1.5 设计文档 —— 套路体系重构:五母套路 + 8 新模型 + 辨题快闪

> 2026-07-08。基于三份调研(内审分类正确性 / 外研经典套路全景 / 外研解题技能与组织法)。
> 调研结论详见本文档末尾"调研摘要"。

## 0. 本版回答的三个问题

1. **现有分类正不正确?** —— 大体站得住(12/15 归属合理),但有 2 个模型放错家族、若干信号词/口诀有硬伤、"基础综合"是个 135 题的未分类抽屉(占全库 1/3)。本版全部修正。
2. **还缺哪些经典套路?** —— 补齐第一梯队 8 个:和差、和倍差倍、归一归总、平均数移多补少、年龄、利润折扣、植树间隔、周期;新立第五母套路「点段定位」;新立「图形与度量」分类接收 basic 里的几何题。
3. **还缺什么技能训练、怎么组织?** —— 实证最强的是"辨题交错训练"(只给题干选套路),本版落地为**辨题快闪**;线段图四选一与多步组合题列入 v1.6 路线图。

## 1. 套路体系 v2(五母套路 + 两个题库分类)

| 母套路 | 成员(★=v1.5 新增,→=v1.5 移入) | 思想 |
|---|---|---|
| 一、守恒锚点 | 单边不变 / 内部转移 / 差额不变 / ★年龄问题 / ★平均数·移多补少 | 什么没变? |
| 二、统一尺度 | ★和倍差倍(族首地基) / 公倍切分 / →双变比例 / 差价代换 / 等值代换 / 量率对应 / ★利润折扣 / →余数层层剩余 | 切成同一把尺子 |
| 三、落差剥离 | ★和差问题(第 0 课) / 鸡兔假设法 / 盈亏缺口 / 容斥重叠 | 抹平差距、假设修正 |
| 四、过程效率 | ★归一归总(族首) / 行程追及相遇 / 工程合作 / 逆推还原 | 过程与速率 |
| 五、点段定位 ★新家族 | ★植树间隔 / ★周期问题 | 离散结构里数对位置:点与段、余数定位 |
| (题库分类) | 基础综合(瘦身后) / ★图形与度量(从 basic 分出 23+ 道) | 无生成器,题库直练 |

**移动理由**(内审报告):双变比例"什么都变了",与守恒家族问句自相矛盾,思想上是份数技术 → 统一尺度;层层剩余的近亲(related 字段)是 base_mapping 与 work_backwards,与"剥落差"无关 → 统一尺度(与量率对应相邻)。模型 id 不变,只动 families.ids,历史数据零迁移。

**新模型 id**:`sum_diff` 和差 / `ratio_units` 和倍差倍 / `unit_rate` 归一归总 / `average` 平均数移多补少 / `age_diff` 年龄 / `profit_discount` 利润折扣 / `interval` 植树间隔 / `cycle` 周期 / `geometry` 图形与度量(词条,无生成器)。

## 2. 词条修正(内审抓的硬伤)

- `speed_catchup` 口诀只盖追及不盖相遇 → 改为"相遇用速度和,追及用速度差"并同步 beats;
- `flatten_assume` 信号词"每人 5 支 + 剩 2 支"是盈亏的半个信号 → 删除,换成"两类东西混着数,总头数和总脚数都给了"类;
- `unify_sub_diff` 与 `flatten_assume` 信号词几乎一致 → 把真正区分点("数量相同 vs 给出总件数")写进信号词;
- `anchor_single` 避坑"把不变的量设为 1 份"过度一般化 → 限定到分数比例子类;
- `work_rate` 避坑"不要假设工程量=1"表述改为教学取舍说明;
- 同构点破:总差÷单差(unify_sub_diff)/差值÷单体差(flatten_assume)/缺口÷单次差(flatten_gap)在三者 related/disambiguation 里互相点名"一个思想三种皮"。

## 3. 新模型内容配置

每个新模型配齐(与现有 schema 一致):词条(signals/pitfalls/memory{cue,mantra,beats,classic,archetypes,emoji}/disambiguation/progression/confusable)+ 参数化生成器((tag,level,seed) 确定、正整数答案、中英双语、3-5 步讲解、两级提示)+ 三档难度。

- **无绘本图**:新模型 `img: null`,卡片/学堂显示 `memory.emoji` 大字占位(后续可补图);
- **无名师例题**:学堂例题区回退为"生成 3 道标准例题"(seed 固定 1/2/3 × 难度 1/2/3,步骤即讲解)——生成题自带 steps,零内容成本;
- **confusable(易混对表)**:每个模型(含旧 15 个)标 2-3 个最易混模型,供辨题快闪出干扰项。

## 4. 真题重归类(basic 瘦身)

代理逐题审 135 道 basic:能明确归入现有/新模型的重归(内审抽样显示约 37%,含 b5_q56→anchor_double 这种教科书案例、27 道和倍差倍、23+ 道几何→geometry);拿不准的保留 basic。输出 `tests/retag-v15.json` 映射 + 脚本应用(沿用 v1.2 audit 先例)。历史 attempts/errorBook 存的是题目快照 tag,不迁移(无害);错题复习按新 tag 配变式反而更准。

## 5. 辨题快闪 `#/quiz`(本版核心技能训练)

- **形式**:只给题干不解题,四选一"这是哪个套路"。干扰项 = 正确模型的 confusable 表 + 同族兄弟。10 题一轮,即时反馈;答错时并排展示"你选的模型典型题 vs 正确模型典型题"对比。
- **题源**:题库题(已归类的 408-135)+ 生成题混合;只用孩子"学过"(masteryLevel≥1)的模型 + 1 个新面孔,累积交错。
- **记录**:`quizLog: [{ts, tag, pick, correct}]`(封顶 1000,同步按 ts+tag 去重合并);首页每模型卡显示"辨题正确率"小字;辨题成绩不进错题本(它不是解题错误)。
- **入口**:首页 hero 行动区 + 快速出题面板旁。

## 6. 混合卷(交错练习上纸)

打印中心卷面选项加"**不印题型名**"开关(勾上后 `p-badge` 模型名不印)——混合卷不泄露类别,配合快速出题的母套路/薄弱范围即成交错试卷。

## 7. 非目标(列入 v1.6 路线图)

- 线段图 bar model 四选一(参数化 SVG 正误图)——调研第 2 优先,工程量大,单独一版做;
- 多步组合题生成器(模型串联)与"下一步求什么"交互;
- 第二梯队套路:分段计费、流水行船、火车过桥、环形跑道、牛吃草、浓度、方阵、页码、抽屉、最优化;
- 干扰数字注入、审题圈词、编题官。

## 8. 验收标准

1. `gen.test.mjs` 自动覆盖 23 个生成器(15+8)全量校验通过(≈27600 题);
2. 每个新模型:学堂页可看(词条+3 道生成例题)、刷题机可刷、快速出题可选、可进错题本与纸卷;
3. 辨题快闪:一轮 10 题可完成,答错有对比讲解,首页可见辨题正确率;
4. basic 重归类后各新模型都有真题背书(interval/cycle 等若真题为 0,题库筛选不出现空分类崩溃);
5. 老数据兼容:旧 localStorage/Gist 数据加载正常,移动家族不影响历史统计。

## 附:调研摘要

1. **内审**(库内证据):12/15 归属合理;anchor_double、fraction_rem 放错家族(related 字段自证);logic_overlap 0 真题、anchor_double 2 道、flatten_assume 3 道在饿死;basic 抽样 37% 可重归;信号词冲突 4 处、口诀不严谨 3 处。

3. **外研教学法**(schema-based instruction + 交错练习实证):"辨题"是题型多了之后的最大瓶颈,交错练习延迟测试 72% vs 分块 38%;bar model 是跨题型压缩器;例规法(先例后规)优于规例法;信号词应绑定结构而非运算符。
