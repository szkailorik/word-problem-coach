# 应用题教练 · Word Problem Coach

> 专教小朋友做数学应用题的训练网站。「数学特训引擎 V28」(wp.kailorik.com) 的全新一代:
> 保留 15 大心智模型方法论和 408 道 SAP 真题,重写为「自动判分 + 无限同类题生成 + 错题间隔复习」的闭环训练系统。

## ✨ 这一代解决什么

| 上一代痛点 | 这一代方案 |
|---|---|
| 一天 3 题铺在 A4 卷面上,家长评分 | **一题一屏**,输入答案**自动判对错**,两次机会 |
| 讲解卡片十几种一次全出,信息过载 | 名师三阶例题**逐步展开**:每次只翻一步,讲完即测 |
| 错题有归档、无复习节奏 | 错题自动入本,**莱特纳盒 1/3/7/14 天**自动排期,连闯 4 关才算彻底掌握 |
| 变式题人工预写,每模型仅 2~12 道 | **15 个参数化出题引擎**,每个模型无限生成新题(中英双语 + 分步讲解 + 精确答案),数字干净、答案必为正整数 |

## 🧩 功能地图

- **首页**:四大母套路(守恒锚点/统一尺度/落差剥离/过程效率)→ 15 模型卡;**掌握地图**:每模型四级阶梯(⚪未学 → 🌱学习中 → 💪熟练 → 🏆精通),母套路各有聚合进度条
- **快速出题** ⚡(首页面板):范围(薄弱优先 / 母套路 / 单模型)× 难度 × 数量,三步选完 → **上屏刷题**或**组卷打印**
- **模型学堂** `#/learn/<tag>`:绘本记忆图 + 口诀 + 信号/避坑/别认错 + 名师三阶例题(标杆/迁移/压轴,逐步展开)
- **刷题机** `#/drill/<tag>`:无限生成同类题,三档难度,提示阶梯(认题型 → 第一步 → 全步骤讲解)
- **每日特训** `#/drill/daily`:到期错题变式 + 薄弱模型新题,共 6 题
- **SAP 101 题库** `#/bank`:**通关图**(未做⚪/做对✅/还要训练🔴/已掌握🏆 一眼全景)+ 按册/模型/状态筛选,一题一屏自评
- **错题本** `#/errors`:到期队列 + 闯关进度;每道错题随时"再练一道同类";一键把到期错题送去打印
- **训练档案** `#/log`:近 7 天节奏柱状图 + 按天回看做了几题、对几题、哪些模式(含纸卷),逐题明细可展开
- **打印中心** `#/print`:筛选/勾选题库题或生成新题 → 每题可附 1~2 道同类变式 → 输出 A4 卷面(宋体、作答区、答题线)+ 独立答案讲解页,屏幕预览即打印效果;点打印自动存档并给卷面印**卷号**
- **批改中心** `#/grade`:纸卷做完后凭卷号找卷,逐题点 **✓/✗** 快速回录 → 自动写入训练档案,错题自动进错题本按 1/3/7/14 天复习,错题在纸卷上做对同样正常升关;已录结果锁定,未录的可补录
- **云同步** ☁️:GitHub Gist 跨设备同步(粘贴 PAT 即连,自动拉取+防抖推送,合并去重);卷子档案也同步,两台设备各批一部分会逐题合并;另有 💾 导出/导入 JSON 备份
- 双学生档案(KAI / Lorik)、中英双语切换

## ✅ v1.4 批改闭环(2026-07-08)

## 🎲 出题引擎

`js/gen/generators.js` 为 15 个模型各实现一个构造式生成器:

- 由 `(tag, level, seed)` 完全确定,同一 id 永远复现同一道题(错题本只存 id,不存题面)
- **先定答案、再倒推题面**:所有中间步骤和最终答案保证为干净的正整数
- 每题自带:中英题干、3~5 步带标签讲解、两级提示、验算句
- 测试:`node tests/gen.test.mjs`(15 模型 × 3 难度 × 400 种子 = 18000 题全量校验)
